# SWIR OS canonical repository policy

`Swir/SWIR_OS` is the canonical source repository for the entire SWIR OS project.

All implementation work belongs here, including Web Edition, Desktop Edition, System Edition, native applications, system services, package/provider infrastructure, Windows compatibility, hardware and driver services, CI contracts, technical documentation, the measurable roadmap, builds and releases.

`Swir/swir.github.io` is presentation-only. It may publish the current verified progress, edition status, milestone summaries and links to this repository or its releases, but it must not become an independent source tree for SWIR OS implementation.

The authoritative roadmap is `SWIR-OS-ARCHITECTURE.md` in this repository. Public progress shown elsewhere must be derived from that roadmap after the corresponding implementation and verification gates have passed.
