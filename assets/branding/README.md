# SWIR OS Branding

This directory contains the reusable visual identity assets for SWIR OS.

- `swir-os-logo.svg` — official horizontal SWIR OS logo/wordmark for documentation, release pages and system surfaces.
- `/swir-icon.svg` — canonical scalable SWIR OS icon used by the Web/PWA edition.
- `/desktop/windows/swir-os.ico` — Windows application icon embedded into the Desktop Edition executable.

The branding intentionally avoids version numbers so the same identity can be reused across Web, Desktop and System editions.
